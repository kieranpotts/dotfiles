= Custom Oh-My-Posh themes

:link-omp-colors: https://ohmyposh.dev/docs/configuration/colors
:link-devtools: https://github.com/kieranpotts/devtools
:link-ocean-theme: https://marketplace.visualstudio.com/items?itemName=kieranpotts.ocean-vscode-theme
:link-terminal-theme: https://glitchbone.github.io/vscode-base16-term/#/ocean

The "ocean" theme was originally a fork of Agnoster, a popular theme included
with Oh-My-Posh by default.

The color scheme uses the {link-omp-colors}[terminal's own color palette]. It is
designed to be used with the "ocean" theme I have configured for Windows
Terminal (via my {link-devtools}[devtools]) and VS Code's integrated terminal
(via {link-ocean-theme}[this VS Code extension]).

My own "ocean" theme was originally inspired by the "ocean" theme of Adrien
Glitchbone's {link-terminal-theme}[base16 terminal color scales generator] for
VS Code.
