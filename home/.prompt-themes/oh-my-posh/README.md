# Custom Oh-My-Posh themes

The "ocean" theme was originally a fork of Agnoster, a popular theme included with Oh-My-Posh by default.

The color scheme uses the [terminal's own color palette](https://ohmyposh.dev/docs/configuration/colors). It is designed to be used with the "ocean" theme I have configured for Windows Terminal (via my [devtools](https://github.com/kieranpotts/devtools)) and VS Code's integrated terminal (via [this VS Code extension](https://marketplace.visualstudio.com/items?itemName=kieranpotts.ocean-vscode-theme)).

My own "ocean" theme was originally inspired by the "ocean" theme of Adrien Glitchbone's [base16 terminal color scales generator](https://glitchbone.github.io/vscode-base16-term/#/ocean) for VS Code.
