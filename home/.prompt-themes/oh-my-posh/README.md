# Custom Oh-My-Posh themes

The "ocean" theme was originally a fork of Agnoster, a popular theme included with Oh-My-Posh by default. It is inspired by the "ocean" theme of Adrien Glitchbone's [base16 terminal color scales generator](https://glitchbone.github.io/vscode-base16-term/#/ocean) for VS Code.

The color scheme uses the [terminal's own color palette](https://ohmyposh.dev/docs/configuration/colors).
